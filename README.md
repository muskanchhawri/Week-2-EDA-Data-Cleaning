# Week 2 - Exploratory Data Analysis (EDA)

## About the Project
This project focuses on data cleaning, preprocessing, and Exploratory Data Analysis (EDA) using Python. The objective is to understand the dataset, identify potential outliers, analyze relationships between variables, and create meaningful visualizations.

## Tasks Performed
- Loaded and explored the student dataset using Pandas.
- Checked for missing values.
- Identified and removed duplicate records.
- Detected potential outliers using the IQR method.
- Practiced categorical encoding using One-Hot Encoding.
- Applied Min-Max Feature Scaling.
- Analyzed relationships between Age and Marks.
- Performed correlation analysis.
- Created visualizations using Matplotlib.
- Documented key findings and conclusions.

## Dataset
The dataset contains the following columns:
- Name
- Age
- Marks

## Tools and Libraries
- Python
- Pandas
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## Files Included
- `student_data.csv` - Original student dataset.
- `cleaned_student_data.csv` - Cleaned dataset after removing duplicate records.
- `Week2_EDA_Assignment.ipynb` - Jupyter Notebook containing analysis, preprocessing, and visualizations.

## Key Findings
- The original dataset contained 5 records, including one duplicate.
- After removing duplicates, 4 unique student records remained.
- The IQR method flagged a potential outlier in the Marks column.
- Visualizations and correlation analysis were used to explore the numerical variables.

## Conclusion
This project provided practical experience in data cleaning, preprocessing, outlier detection, feature scaling, correlation analysis, and data visualization using Python.
